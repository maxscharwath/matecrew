## What Claude can do

Claude acts as **you**, it gets exactly your own access, never more:

- Place, switch and cancel your orders, and take a can from the fridge
- Read the stock, the weekly schedule and the office statistics
- Serve a whole round when you are the one fetching them
- See what you owe and what you are owed

If you are an office admin, it can also manage stock, purchases, members, the
schedule and reimbursements, but only in the offices where you are already an
admin. Being an admin in Lausanne grants Claude nothing in Genève.

## Getting set up

Head to [your profile](/profile#claude) and follow the Claude Code steps. It
takes about a minute:

<Terminal
  lines={[
    { cmd: "claude mcp add --scope user --transport http matecrew https://matecrew.vercel.app/api/mcp", out: "Added HTTP MCP server matecrew" },
    { cmd: "claude", out: "/mcp → matecrew → Authenticate  (opens your browser)" },
    { cmd: "claude mcp list", out: "matecrew  ✓ Connected" },
  ]}
/>

<Callout>
  Adding MateCrew in the Claude **web or desktop** app is controlled by your
  Claude organisation's settings, and ours currently disables custom connectors.
  Use Claude Code in the terminal, where there is no such restriction.
</Callout>

## Is it safe?

Access is granted per person through a normal sign-in, and you can cut it off at
any time from **Profile → Connect to Claude → Connected apps**. Disconnecting
only affects your own access; colleagues using Claude keep theirs.
