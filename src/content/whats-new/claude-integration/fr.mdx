## Ce que Claude peut faire

Claude agit en **votre nom**, il obtient exactement vos propres droits, jamais
davantage :

- Passer, changer et annuler vos commandes, ou prendre une canette au frigo
- Consulter le stock, le planning hebdomadaire et les statistiques du bureau
- Servir toute une tournée quand c’est vous qui allez les chercher
- Voir ce que vous devez et ce qu’on vous doit

Si vous êtes administrateur d’un bureau, il peut aussi y gérer le stock, les
achats, les membres, le planning et les remboursements, mais uniquement dans les
bureaux où vous l’êtes déjà. Être administrateur à Lausanne ne donne aucun droit
à Claude sur Genève.

## Mise en place

Rendez-vous sur [votre profil](/profile#claude) et suivez les étapes Claude Code.
Comptez environ une minute :

<Terminal
  lines={[
    { cmd: "claude mcp add --scope user --transport http matecrew https://matecrew.vercel.app/api/mcp", out: "Added HTTP MCP server matecrew" },
    { cmd: "claude", out: "/mcp → matecrew → Authenticate  (ouvre votre navigateur)" },
    { cmd: "claude mcp list", out: "matecrew  ✓ Connected" },
  ]}
/>

<Callout>
  L’ajout de MateCrew dans l’application Claude **web ou desktop** dépend des
  paramètres de votre organisation Claude, et la nôtre désactive actuellement les
  connecteurs personnalisés. Utilisez Claude Code dans le terminal, où cette
  restriction n’existe pas.
</Callout>

## Est-ce sûr ?

L’accès est accordé individuellement via une connexion classique, et vous pouvez
le couper à tout moment depuis **Profil → Connecter à Claude → Applications
connectées**. Se déconnecter n’affecte que votre propre accès ; vos collègues qui
utilisent Claude conservent le leur.
